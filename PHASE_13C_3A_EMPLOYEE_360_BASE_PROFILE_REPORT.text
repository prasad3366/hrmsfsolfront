PHASE 13C-3A - EMPLOYEE 360 BASE PROFILE REPORT

Scope
-----
Implemented the first Employee 360 UI increment for Base Profile, Personal information, Employment information, and Contact information only.

Exact files changed for this phase
-----------------------------------
- src/modules/employees/EmployeeProfile.tsx
- PHASE_13C_3A_EMPLOYEE_360_BASE_PROFILE_REPORT.text

UI sections added
-----------------
EmployeeProfile.tsx now has a compact tab structure with:
- Personal (default/first visible section)
- Employment
- Contact

The existing profile header, routing, Edit action, Give Raise action, loading state, error state, styles, and responsive layout remain in place.

Safe fields displayed
---------------------
Personal:
- firstName
- lastName
- user.email
- phone

Employment:
- empCode
- department
- designation
- team.name
- user.role
- employmentType
- status, formatted as Active, Inactive, On Leave, or Terminated
- dateOfJoining

Contact:
- city
- phone

These fields are present in the safe GET /employees/:id/360 projection. The removed display cards do not render PAN, Aadhaar, government IDs, bank account information, salary, payroll, PF, UAN, document file content, or asset data.

APIs used
---------
- Initial profile data uses ApiService.getEmployee360(Number(id)), which calls GET /employees/:id/360.
- The previous broad employee API is not used for displaying the 360 sections.
- The existing detailed ApiService.getEmployeeById() call remains only behind the existing Edit action so the edit form keeps its complete field population.
- No new API calls, endpoints, authorization rules, role checks, or data structures were added.
- No Performance UI was added; Performance remains deferred.

Preserved behavior
------------------
- Existing /employees/:id routing and backend-controlled self/target authorization remain unchanged.
- Edit still loads detailed employee data only when Edit is opened.
- Give Raise remains unchanged.
- No frontend-only role/team/manager authorization decision was added.
- No attendance, leave, hierarchy, assets, documents, or payroll UI was added in this phase.
