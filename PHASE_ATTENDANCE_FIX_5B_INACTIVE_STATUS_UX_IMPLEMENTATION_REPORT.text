Exact behavior changed
----------------------

  runs before the existing general error is set.

establishing current status invalidates the cached todayRecord.

current-status data no longer controls the punch label or modal. Attendance
falls back to the existing no-status behavior instead of retaining stale
Check Out or View state. The existing error and warning behavior remains.
