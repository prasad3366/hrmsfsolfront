Changes made
------------

AdminDashboard:
- Removed simulated financial chart generation based on employee count and
  Math.random(). The existing chart area now clearly displays that financial
  history is not available because no supported historical financial API data
  is loaded by this Dashboard.
- Removed the calculated attrition approximation and its fabricated trend. The
  card now shows Not available / Not provided.
- Kept the real employee count and new-hire count from the existing employee
  API request.
- Renamed the WFH-derived Active Projects card to Active WFH Arrangements,
  accurately reflecting the existing API-backed data without inventing project
  data.
- Payroll Cost now shows actual calculated payroll data only when the existing
  payroll collection is populated; otherwise it shows Not available. Existing
  payroll API error handling remains visible through the D2 banner.

HRDashboard:
- Replaced hardcoded Attendance Today 92% and 8% up text with a percentage
  derived from the existing attendance API records for the current day.
- Shows Not available when no current-day records exist and Error when the
  attendance API reports an error.
- All existing employee, WFH, leave, helpdesk, and attendance loading/error
  behavior remains in place.

ManagerDashboard:
- Removed the fallback 88% team-attendance value. The card now shows actual
  attendance-derived data or Not available.
- Removed hardcoded task metric defaults and fabricated task chart values;
  Active Tasks, Completed Tasks, and Task Progress now show Not available when
  the backend provides no task data.
- Removed random productivity scores and mock employee fallback from the
  performance section; unsupported performance data now shows Not available.
- Replaced the hardcoded 7/10 task value in the team table with Not provided.
- Existing API-backed team member counts remain unchanged.

EmployeeDashboard:
- Replaced hardcoded Goals Progress 72% and Q1 objective text with Not
  available / Not provided by the API because no goals endpoint/data is used.
