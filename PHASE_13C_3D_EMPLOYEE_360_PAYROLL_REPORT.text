PHASE 13C-3D - EMPLOYEE 360 PAYROLL REPORT

Scope
-----
Added only the Payroll tab/section to the existing EmployeeProfile Employee 360 UI. Existing Personal, Employment, Contact, Attendance, Leave, Hierarchy, Assets, Documents, Edit, Give Raise, and routing behavior remain in place. Performance was not added.

Exact files changed for this phase
-----------------------------------
- src/modules/employees/EmployeeProfile.tsx
- src/services/api.ts
- src/services/api.test.ts
- PHASE_13C_3D_EMPLOYEE_360_PAYROLL_REPORT.text

API used
--------
- ApiService.getEmployee360Payroll(Number(employee.id))
- GET /employees/:id/360/payroll

The Payroll tab is lazy-loaded only when opened. It does not call /payroll, /payroll/my, salary target endpoints, payslip endpoints, or any broad payroll API.

Safe fields displayed
---------------------
For each safe 360 payroll record:
- Month (backend field: month)
- Year (backend field: year)
- Status (backend field: status)
- Gross (backend field: grossSalary)
- Deductions (backend field: deductions)
- Net (backend field: netSalary)
- Salary Effective Date, when present (backend field: latestSalaryEffectiveDate)

Sensitive fields excluded
-------------------------
The Payroll 360 section does not request, derive, or render:
- Bank account details
- PAN
- Aadhaar/government IDs
- UAN
- PF details
- Full salary structure
- Basic, HRA, allowance, or other salary breakdown fields
- Payslip PDF/file content
- Payslip download URLs
- Any broad payroll response fields

Loading, empty, and error behavior
----------------------------------
- Independent loading state: Loading payroll...
- Independent API error state: Unable to load payroll: <error>
- Independent empty state: No payroll records available.
- A failed request sets payroll data to null, so an API failure cannot render the empty-record message.
